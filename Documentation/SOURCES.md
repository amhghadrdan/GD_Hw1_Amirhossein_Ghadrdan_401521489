# منابع و انتساب

- صورت مسئله: `HM1.pdf` موجود در ریشهٔ پروژه.
- راهنمای رسمی Unity Input System: https://docs.unity3d.com/Packages/com.unity.inputsystem@1.7/manual/index.html
- راهنمای رسمی Input System UI: https://docs.unity3d.com/Packages/com.unity.inputsystem@1.7/manual/UISupport.html
- مستندات Animator: https://docs.unity3d.com/2022.3/Documentation/Manual/AnimatorControllers.html
- مستندات PlayerPrefs: https://docs.unity3d.com/2022.3/Documentation/ScriptReference/PlayerPrefs.html
- تمام تصاویر پیکسلی، جلوه‌ها، افکت‌های صوتی و موسیقی به‌صورت اختصاصی و قابل‌بازتولید با `Tools/generate_assets.py` تولید شده‌اند؛ از Asset Store یا بازی Chrome کپی نشده‌اند.
- فونت Lato، ساختهٔ Łukasz Dziedzic، تحت SIL Open Font License 1.1؛ متن مجوز در `FONT-LICENSE.txt` قرار دارد. منبع: https://www.latofonts.com/
- کد و مستندات این پروژه با کمک OpenAI Codex تهیه شده‌اند. صورت تمرین درخواست ذکر منابع و همفکری کرده است؛ این توضیح را در گزارش تحویل حفظ کنید.

مشخصات دانشجو و لینک واقعی مخزن در گزارش PDF و repository.txt درج شده است.

- بازطراحی ساحل نمکی با تولید و ویرایش کدنویسی‌شدهٔ دارایی‌های پیکسلی در همین پروژه انجام شده است؛ جزئیات طراحی در DESIGN.md ثبت شده‌اند. استفاده از Codex در کد و مستندات مطابق بند بالا اعلام شده است.

- بستهٔ اجرای تک‌فایلی با NSIS 3.10 ساخته شده است. اسکریپت آن در Tools/Portable/DuneDashPortable.nsi و توضیحات و منابع رسمی در PORTABLE.md قرار دارند.
