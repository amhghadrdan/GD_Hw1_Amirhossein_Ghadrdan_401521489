# Salt Coast — طراحی بصری ساحل نمکی

این نسخه برای یک ماجراجویی در ساحل نمکی طراحی شده است. شال کهربایی، بدنهٔ سبزآبی و کولهٔ کوچک، کاراکتر را به یک کاوشگر تبدیل می‌کنند. ماه حلقه‌دار و لایه‌های صخره‌ای، فضای محیط را شکل می‌دهند.

| کاربرد | رنگ |
|---|---|
| خطوط و متن اصلی | `#1C3049` |
| بدنهٔ کاراکتر | `#63C4A2` |
| شال، پاداش و دکمهٔ اصلی | `#E4B970` |
| آسمان | `#DCE9EC` |
| صخرهٔ دور / میانی / نزدیک | `#AAC3CC` / `#779CAA` / `#4F7289` |
| زمین نمکی | `#87A5B0` |
| سطح روشن رابط | `#F1F5EE` |

- کاراکتر در حالت‌های دویدن، پرش و آسیب شال، کوله و تاج کوچک دارد. ژست مرگ نیز با لباس جدید هماهنگ شده است.
- موانع زمینی شکل صخره‌های بلوری با رگهٔ کهربایی دارند. پرندگان، باله و دم متمایز دارند و در دو ژست رسم می‌شوند.
- سکه‌ها به شکل تراش‌خورده با سطح روشن و سایهٔ کهربایی رسم می‌شوند.
- پس‌زمینه از لایه‌های پیوستهٔ صخره‌ای ساخته می‌شود. کف، بلورهای نمک و خطوط رسوبی دارد.
- پنل روشن منوی اصلی، خوانایی متن را روی صخره‌های تیره حفظ می‌کند. رنگ ذرات گردوغبار با کف آبی هماهنگ شده است.

دارایی‌ها با `python3 Tools/generate_assets.py --art-only` بازتولید می‌شوند. ابعاد، نقطهٔ اتصال، شناسه‌های Sprite و مسیرهای Resources با Animator و Prefabهای پروژه سازگار نگه داشته شده‌اند. نام‌های فنی قدیمی مانند `Cactus.png` برای سازگاری با همان منابع و مسیرهای اجرایی حفظ شده‌اند.

کد و مستندات با کمک OpenAI Codex تهیه شده‌اند؛ منابع و مجوزها در SOURCES.md هستند.
